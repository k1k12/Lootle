# Security

## Reporting a problem

Please do not open a public issue for a security problem. Use
[private vulnerability reporting](https://github.com/k1k12/Lootle/security/advisories/new)
instead, which sends the report straight to the maintainer.

It helps to include:

- what you found and where (a URL or file path)
- the steps to reproduce it
- what an attacker could do with it

You should get a reply within a week.

## What counts

Things worth reporting:

- a way to read a safe's answers before finishing it
- a way to change another player's results or the rarity counts in bulk
- a way around the rate limits
- anything that runs someone else's script on lootle.app

Already known and accepted for now: player ids are made in the browser, so
one person can create several. See "Known limits" in the README.

## Supported versions

Only the version currently live at lootle.app is supported.
